# Data and artifact provenance

| Component | Provenance | What it does not claim |
|---|---|---|
| Public case narrative | A generalized summary of work records supplied by the author | Independent verification of an employer's data, role, or results |
| `data/synthetic/` | New pseudorandom data generated by `src/generate_demo.py` | Anonymized or transformed real records; matching a real data distribution |
| Python and SQL | Newly written executable demonstration | Original production code or the historical SEM implementation |
| `outputs/` and statistical figures | Computed from the bundled synthetic data | Actual product quality, business gains or causal effects |
| HTML portfolio | Newly generated self-contained presentation | A screenshot or live instance of an enterprise dashboard |
| Skill, prompts and memory examples | Newly structured public method templates | Original proprietary skills, transcripts, or a running external Agent |
| Weekly summary example | Deterministic rendering of a mock decision log | LLM inference, autonomous collection, continuous model training or personality diagnosis |

No original employer data files or internal systems were accessed. The author-supplied process summary was the sole historical source. No external short links in the original record were followed. No record-level health text, real identifiers, employer documents or credentials are needed to run the demonstration.

Do not place the separately supplied private preparation notes in this repository.
