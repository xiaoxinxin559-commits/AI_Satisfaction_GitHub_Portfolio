01 / 防遗漏

每个字段都要交代去向

不仅检查数值列，也检查标识、分类、多值字段、空列与改版字段。匿名标识 0 不等于所有匿名记录来自同一人。

验收动作：用字段全量清单与源列集合逐项对账。
02 / 防泄漏

问卷规则不能当成产品规律

评分之后才展示的标签，会携带评分本身的信息。即使模型指标更高，也不等于发现了能够改善体验的前因。

验收动作：检查“评分段 × 标签分支”，拦截后验特征。
03 / 防过度解释

系数异常先查原因，不急着讲故事

复核时序、指标定义、相关结构、共线性与软件约束。条件关联与零阶相关可以不同，不能直接解读成干预效果。

验收动作：保留对照结果与决策理由，必要时简化模型。

-- Newly written SQLite demo, not an original production query.
-- One latest valid questionnaire per session; events after the survey are excluded.
-- Known complete event coverage is assumed. With real incomplete logs, missing != zero.
WITH ranked_surveys AS (
    SELECT *, ROW_NUMBER() OVER (
        PARTITION BY session_id ORDER BY survey_time DESC
    ) AS submission_rank
    FROM surveys
), valid_surveys AS (
    SELECT * FROM ranked_surveys
    WHERE submission_rank=1 AND score IN (1,2,3,4,5)
), aggregated AS (
    SELECT s.session_id,
           SUM(CASE WHEN e.event_name='quick_result_count' THEN 1 ELSE 0 END) AS quick_result_count,
           SUM(CASE WHEN e.event_name='consult_result_count' THEN 1 ELSE 0 END) AS consult_result_count,
           SUM(CASE WHEN e.event_name='followup_shown_count' THEN 1 ELSE 0 END) AS followup_shown_count,
           SUM(CASE WHEN e.event_name='followup_click_count' THEN 1 ELSE 0 END) AS followup_click_count
    FROM valid_surveys s
    LEFT JOIN events e ON e.session_id=s.session_id
      AND e.event_time <= s.survey_time
      AND julianday(e.event_time) >= julianday(s.survey_time)-1
    GROUP BY s.session_id
)
SELECT s.session_id, s.score, a.quick_result_count, a.consult_result_count,
       a.followup_shown_count, a.followup_click_count
FROM valid_surveys s
LEFT JOIN aggregated a ON s.session_id=a.session_id
ORDER BY s.session_id;

"""Explicit field inventory, survey gating checks, and session-level cleaning."""
import numpy as np
import pandas as pd
from .schema import CATALOG, COUNT_FEATURES, POS_TAGS, NEG_TAGS, FORBIDDEN_FEATURES


def field_inventory(raw: pd.DataFrame) -> pd.DataFrame:
    rows=[]
    for c in raw.columns:
        title,role,reason=CATALOG.get(c,(c,"needs_review","未知字段：先确认口径，不可自动入模"))
        nonempty=raw[c].replace(r"^\s*$",np.nan,regex=True)
        n_unique=int(nonempty.nunique(dropna=True))
        missing=float(nonempty.isna().mean())
        flags=[]
        if missing==1: flags.append("all_missing")
        elif n_unique<=1: flags.append("constant")
        if role=="gated_label": flags.append("target_leakage_risk")
        if role=="versioned": flags.append("cross_period_break")
        rows.append(dict(field=c,title=title,role=role,reason=reason,
                         missing_pct=missing*100,n_unique=n_unique,flags=";".join(flags)))
    return pd.DataFrame(rows)


def clean_sessions(raw: pd.DataFrame) -> tuple[pd.DataFrame, dict]:
    required=set(CATALOG)
    if missing:=required-set(raw.columns):
        raise ValueError(f"Missing demo columns: {sorted(missing)}")
    df=raw.copy()
    if df["session_id"].isna().any():
        raise ValueError("A session_id is required; do not deduplicate on user_id.")
    df["survey_time"]=pd.to_datetime(df["survey_time"],errors="raise")
    df=df.sort_values(["session_id","survey_time"],kind="stable").drop_duplicates("session_id",keep="last")
    after_dedup=len(df)
    df["score"]=pd.to_numeric(df["score"],errors="coerce")
    valid=df["score"].isin([1,2,3,4,5])
    invalid=int((~valid).sum())
    df=df.loc[valid].copy()
    df["score"]=df["score"].astype(int)
    for c in COUNT_FEATURES:
        values=pd.to_numeric(df[c],errors="coerce")
        if values.isna().any() or (values<0).any():
            raise ValueError(f"Unconfirmed missing/negative count in {c}; do not silently fill.")
        df[c]=values
    uid=df["user_id"].fillna("0").astype(str)
    is_anon=uid.isin(["0","0.0",""])
    anonymous=df["anonymous_id"].fillna("").astype(str)
    fallback=is_anon & anonymous.eq("")
    df["is_anonymous"]=is_anon.astype(int)
    df["participant_key"]=np.where(~is_anon,"u:"+uid,
            np.where(~fallback,"a:"+anonymous,"s:"+df["session_id"].astype(str)))
    # Missing age is modeled explicitly; this is not a universal missing-data remedy.
    df["age_unknown"]=df["age_level"].isna().astype(int)
    df["age_level"]=df["age_level"].fillna(0)
    log={"raw_rows":len(raw),"unique_sessions_before_outcome_filter":after_dedup,
         "duplicate_rows_removed":len(raw)-after_dedup,"invalid_outcome_rows_removed":invalid,
         "valid_sessions":len(df),"anonymous_sessions_retained":int(is_anon.sum()),
         "session_key_fallbacks":int(fallback.sum()),"unit":"session/questionnaire, not unique persons"}
    return df.sort_values("session_id").reset_index(drop=True), log


def check_gating(df: pd.DataFrame) -> dict:
    pos=df[POS_TAGS].sum(axis=1)>0
    neg=df[NEG_TAGS].sum(axis=1)>0
    return {"positive_tags_at_low_score":int((pos & (df.score<=3)).sum()),
            "negative_tags_at_high_score":int((neg & (df.score>=4)).sum()),
            "mixed_branch_tags":int((pos & neg).sum()),
            "no_tag_selected":int((~pos & ~neg).sum()),
            "warning":"Rules must be checked against the questionnaire; zero violations do not prove causality or independence."}


def validate_feature_allowlist(features: list[str]) -> None:
    if bad:=set(features)&set(FORBIDDEN_FEATURES):
        raise ValueError(f"Outcome/post-outcome features are forbidden: {sorted(bad)}")

# 满意度分析协作 Skill

本文件依据工作记录中的方法重新编写，不是原企业 Skill，不包含专有工具接口，也不代表已经安装到任何 Agent 平台。应按目标平台格式进行适配和测试。

## 先确认

一次性问清分析目标、样本单元、评分尺度、事件窗口、问卷跳转规则、可交付范围与数据权限。分清解释关联、预测和因果评估。字段不明确先问，不自行改名或猜测。

## 执行阶段

1. 逐字段盘点：所有字段都要有角色、覆盖率、变异情况和去向，包括 ID、类别、多值字段与空列。
2. 数据质量：核对去重主键、匿名标识、无效评分、埋点断裂、缺失机制与异常值；不为提高拟合度随意删样本。
3. 时序检查：区分事前特征、同期反馈、评分后标签与下游结果。评分门控标签不得直接进入预测前因。
4. 模型方案：依据连续近似、二元、有序或计数结果选择模型。使用潜变量时先审查识别与测量假设，不能只追拟合指标。
5. 诊断：异常系数先查口径、样本、相关结构、共线性与约束；必须确认对比模型真的修改了目标参数。
6. 解释：分别报告零阶关联、条件关联、预测性能及仍待验证的机制。不同量纲的系数与 R² 不直接比较。
7. 交付：代码、参数、结果表、图表底数、结论、建议、局限与版本说明一并保存。外部公开前再次确认权限。

## 人工决策关卡

指标口径、因果方向、模型路线、反直觉结果的解释、产品建议优先级与公开发布须由人确认。Agent 不能自行把假设升级成事实，不能补造数值、引用或已完成的业务收益。

## 输出格式

每个大步骤回答：做什么 → 为什么 → 如何做 → 得到了什么 → 能说明什么、不能说明什么 → 下一步。

每条正式数字注明样本版本、模型版本、估计口径和来源表格。方法图与结果图区分；示意内容写“示意”，合成数据写“合成”。

## 退出与降级

发现不可用字段、门控泄漏、不可识别模型或未收敛结果时，不强行给结论。保留诊断并提出可解释的简化方案。测量证据不足时可以改用显变量分析，但不能把这种回退说成已证明原构念不存在。

## 记忆与复盘

只保存经用户确认的非敏感协作偏好、版本决策与方法教训。禁止在公开记忆中保存原始健康对话、个人标识、公司链接或凭证。推测的工作风格需标注推测，不作人格或心理诊断。

哪些可以交付，哪些还需要验证？

为什么没有把 MCP、RAG、Multi-Agent 都放进项目标签？

调用一个平台的 Agent、分析带有工具调用字段的数据，与独立搭建 MCP 服务、检索系统或多 Agent 编排不是同一项经历。本项目只展示有记录支持的方法协作，以及本次实际新增的离线代码。

为什么不以更高的 R² 作为项目主成绩？

不同目标与估计方法下的 R² 不可直接混比；更高分也可能依赖结果之后的变量。这个项目强调口径、可解释性和交付可复核，而不是追求一个脱离场景的模型分数。

公开与保密边界：本页不提供临床判断，不证明任何真实产品的质量；所有演示数值都来自合成数据。项目经历、原始结果与新建展示代码应分别陈述。发布前仍需由作者确认工作方法摘要的公开权限。
