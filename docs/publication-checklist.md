# 公开发布检查清单

本次新建公开包使用合成数据并移除了公司名、真实人员、内部短链、真实用户对话、原始会话 ID 与企业代码。仍应由作者在上传前完成最终审核。

- [ ] 确认有权公开项目方法摘要与工作经历表述，必要时进一步去除业务背景。
- [ ] 只上传本仓库内容；不要把单独交付的私人核对笔记或原始 Agent 记录一并上传。
- [ ] 不添加真实健康数据、对话截图、用户原声、标识、内部库地址、密钥或环境文件。
- [ ] 让“合成数据 / 新建重构代码 / 非原项目复现”的说明始终可见。
- [ ] 不把截图中的演示数值写成实际业务成绩，不把新生成的 SQL 说成历史原代码。
- [ ] 复核项目职责是否与自己的实际参与一致，未独立开发的工具不写成自研平台。
- [ ] 对原项目真实业务数据与聚合指标，取得单独公开授权后再决定是否添加；哈希 ID 并不等于充分匿名化。
- [ ] 选定源码许可证前确认授权范围。此包没有替作者选择对外开源许可证。
- [ ] 运行脚本、测试并检查 HTML 后，再发布 GitHub Pages。

仓库可先建为私有进行检查；但 Pages 的可用性与访问方式受到账号方案和设置影响。公开演示页应按公开内容审核，不能把私有仓库当作网页必然私有的保证。
